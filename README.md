# Predictive Analytics Using Historical Data

## 📌 Project Overview

This project focuses on Predictive Analytics using historical sales data to forecast future sales trends. The Superstore Sales Dataset was analyzed using Python, machine learning, and time-series forecasting techniques.

The project includes data cleaning, exploratory data analysis, feature engineering, model building, model evaluation, future sales forecasting, and Power BI visualization.

Three models were developed and compared:

- Linear Regression
- Random Forest Regression
- SARIMA

Based on the evaluation results, **Linear Regression was selected as the best-performing model** and was used to forecast sales for the next 12 months.

---

## 🎯 Project Objectives

- Analyze historical sales data and identify important trends.
- Clean and preprocess the dataset.
- Perform exploratory data analysis (EDA).
- Analyze monthly sales patterns.
- Create time-based and lag features.
- Build multiple predictive models.
- Evaluate model performance using MAE, RMSE, and MAPE.
- Select the best-performing model.
- Forecast sales for the next 12 months.
- Generate meaningful business insights.
- Create an interactive Power BI dashboard.
